# Team Assignments

## Member 1 - Frontend
Responsibilities:
- Create the user interface
- Build screens and navigation
- Prepare the visual structure of the project

## Member 2 - Backend
Responsibilities:
- Set up application logic
- Create APIs or core services
- Connect business features to the database

## Member 3 - Testing and Documentation
Responsibilities:
- Write test cases and quality checks
- Prepare documentation
- Support deployment and final presentation

## Shared Work
All members should help with:
- Project planning
- Code review
- GitHub updates
- Final integration
