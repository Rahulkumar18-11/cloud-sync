# Contributing to CloudSync

## Team Rules
- Each member should work on a separate branch.
- Keep commits small and meaningful.
- Write clear commit messages.
- Do not push directly to the main branch without review.

## Branch Naming
Use one of the following patterns:
- feature/member1-frontend
- feature/member2-backend
- feature/member3-testing

## Suggested Commit Style
- member1: add UI layout
- member2: create API structure
- member3: add test plan

## Pull Request Process
1. Push your branch to GitHub.
2. Open a pull request.
3. Add a short summary of your changes.
4. Wait for review and merge.

## Contribution Goal
The aim is to show steady teamwork and visible contribution for a mini project submission.
